# Water Strobe

iPhone Safariの背面カメラ用ライトを周期点滅させ、水滴などの周期運動を観察するための静的Webアプリです。

## 使い方

1. HTTPSでページを開き、「ライトを準備」をタップします。
2. カメラ利用を許可します。
3. 周波数とDutyを選び、「ストロボ開始」をタップします。
4. `±0.1` / `±0.01` または水滴方向ボタンで静止して見える点を探します。
5. 終了時は「ストロボ停止」をタップします。

初期値は10 Hz・Duty 10%です。設定、プリセット、静止ポイントは端末内のlocalStorageへ保存します。カメラ権限は「ライトを準備」を押すまで要求しません。

## 対応と制約

- 主対象はHTTPS上のiPhone Safariです。Torch対応は端末・OS・ブラウザごとに機能検出します。
- PCやAndroidでも画面は開けますが、Torch非対応環境では点滅を開始しません。
- 表示する「JS実行周波数」はJavaScript側の要求周期で、LEDそのものの発光周波数を保証する値ではありません。
- ページが非表示になるとストロボを停止します。端末の省電力・温度・Safariの制御により周期が乱れる場合があります。
- 録画形式はMediaRecorderがその端末で対応しているMIME Typeを自動選択します。保存先の選択はSafari/iOSに委ねます。
- PWA表示よりSafari通常表示の方がカメラ・Torchが安定する場合があります。

## ローカル確認

カメラ機能の確認にはlocalhostまたはHTTPSが必要です。リポジトリ直下でHTTPサーバーを起動し、`http://127.0.0.1:8042/04_water-strobe/` を開いてください。ライト動作は対応するiPhone実機とHTTPS環境で確認してください。
