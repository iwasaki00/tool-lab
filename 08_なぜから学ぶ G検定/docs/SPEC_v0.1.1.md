# SPEC v0.1.1 — STORY FIRST

v0.1.0からの導入改修。教師なし学習・強化学習の本編と独自12問は維持する。以前の全体仕様はSPEC_v0.1.0.mdに記録し、以下を変更する。

## ホームと導入

初回の主ボタンは「出荷ラインを見に行く」。`started`・見本追加・進行位置・閲覧場面・旧予想・回答履歴のいずれかに記録があれば「続きから学ぶ」を優先する。明示的な「導入をもう一度見る」は導入の体験状態のみリセットし、履歴・復習・既存の予想値は消さない。

Scene ID `L003-S01` のタイトルは「良品が、不良品レーンへ。」。導入は一枚のインラインSVG、検査員の短いセリフ、一つの主ボタンで構成する。場面番号のナビ・速度設定・用語説明・3つの依頼カード・予想フォームは初回操作の前に表示しない。途中終了は上部から可能。

主ボタンで別の検査済みの箱Wを見本に追加すると、既存の1最近傍計算が箱Qを再判定する。判定の戻り値に従って、同じSVGの箱Qを良品レーンへ移し、判定とWの追加状態の文字も変える。色だけに依存しない。初期データと対象を変更する操作はなく、追加するのはWのみ。Qを正解つき見本へ登録しない。

## 最初の発見

Q=(60,60)。初期6見本で最も近いのは不良のP4=(68,65)、距離√89。追加される別の良品W=(58,57)は距離√13で、0ではない。W追加後はその良品ラベルがQの予測となる。結果の文言やレーンは計算値から表示する。

操作後にだけ、指定された教師あり学習の説明を表示する。「分類を続けて試す」でScene 02へ進み、Qの特徴と追加済みWを引き継いで既存の詳細操作を利用できる。旧版の途中再開でW未追加なら従来の初期状態を使う。

## 任意の試験問題

場面IDと配列位置は全9場面とも変更しない。Scene 07知識マップの通常の次へはScene 09まとめへ進む。Scene 08演習は「試験問題で確認する」または場面ナビから選べる。まとめの「試験問題で確認する」、メイン「演習」からの直接経路も維持する。

回答が0件でもまとめに進め、演習を除く8場面を閲覧すれば本人の操作で学習完了を記録できる。正答率による習得の断定はしない。回答済みの結果・全履歴・解き直し・復習候補の仕様は継続する。

## 保存・互換・オフライン

既存のDB名・版・object store・バックアップ形式版を維持する。新フィールドは任意のbooleanとして検証し、欠落する旧データを受理する。旧予想の配列も保持する。読込時に進行位置を書き換えたり、強制的に冒頭へ戻したりしない。新しい完了条件に従って、回答なしの完了状態もバックアップ検証対象にする。

インラインSVGはJSバンドルに含まれ、既存SWの全資産事前取得でオフライン対応する。見本追加の状態も逐次保存する。既存のJSON統合・置換確認・不正データ拒否を維持する。

## 表示・検証基準

390×844 CSS pxの通常文字では、導入の挿絵と最初のボタンを初期viewport内に収める。320pxや文字200%相当では縦スクロールを許容し、横溢れ・ボタンや挿絵の重なりを防ぐ。ブラウザのズームは禁止しない。ネイティブbuttonとSVGの読み上げ用説明を用い、判定変化は文字とstatusでも通知する。
