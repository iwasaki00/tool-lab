# L004 教材・判定データ・独自3問

L004「モデル評価」／正解率99％なのに、不良品を見逃した。要件に基づく独自教材で、公式試験問題の転載ではない。

## 物語と照合

同じ工場の翌朝。AIに仕分けを任せる前に、見本に使っていない100箱で試運転する。人の検査結果は照合用であり、見本へ追加しない。第1話を未読でも、導入だけで工場とAIによる良品・不良の仕分けを理解できる。
導入→100箱を流す→Aの見逃しを発見→同じ100箱でBを比較→何を避けたいかを振り返る→試験での呼び方→任意3問／ここで終える。

## データからの集計

データはsrc/data/evaluation.tsの100件。BOX-001〜099が人の検査で良品、BOX-100が不良。Aは全箱を良品判定。BはBOX-001〜097を良品、BOX-098〜100を不良判定とする。再学習を行わず、固定判定の比較を行う。

| 項目 | 仕分けA | 仕分けB |
| --- | --- | --- |
| 評価用の箱 | 100 | 100 |
| 人の検査：良品／不良 | 99／1 | 99／1 |
| 判定一致 | 99 | 98 |
| 正解率 | 99％ | 98％ |
| 不良品の見逃し | 1 | 0 |
| 良品の止めすぎ | 0 | 2 |
| 再現率（不良品を見つけたい対象とする） | 0/1＝0％ | 1/1＝100％ |

混同行列は行が人の検査結果（良品／不良）、列がAI判定（良品として通す／不良として止める）。
Aは [[99, 0], [1, 0]]。Bは [[97, 2], [0, 1]]。

## 結末と用語

この工場では見逃しを減らしたいので、試運転ではBを候補とする。止まった良品2箱は人が再確認する。Bが常に優れているとも、この100箱だけで本番の安全が保証されるとも説明しない。
結果後の『試験での呼び方』で正解率・再現率を説明する。混同行列は『詳しく見る』に配置。

## 独自3問と全選択肢の解説

### L004-Q01 / v1

仕分けAは100箱中99箱で一致。それでも、この工場で困ったのはなぜ？

- A 不正解：99％という計算が間違っていたから
  解説：99箱の良品で一致し、不良1箱で不一致なので99％は正しい計算です。全体の割合だけでは、何を間違えたかが分かりません。
- B 正解：止めたかった不良品1箱を、良品として通したから
  解説：Aは良品99箱を正しく通しましたが、人が不良と確認した1箱も通しました。見逃した箱の種類が、この工場の目的に合いませんでした。
- C 不正解：良品99箱をすべて止めたから
  解説：Aは良品99箱を通しています。良品の止めすぎは0箱で、問題は不良品の見逃し1箱でした。
- D 不正解：人の検査結果をAIの見本に加えなかったから
  解説：今回の100箱は、仕分けを確かめるための別データです。人の検査結果を照合に使い、学習用の見本へ加えないことは誤りではありません。

判断の決め手：99％が正しくても、止めたい不良品を見逃した事実は残る。

### L004-Q02 / v1

この工場で不良品の見逃しを減らしたい。まず確かめたい数字は？

- A 不正解：全体の正解率だけ
  解説：正解率は全体で一致した割合です。Aは99％でも不良1箱を見逃したため、正解率だけでは目的を確かめられません。
- B 不正解：流した箱の総数だけ
  解説：AもBも同じ100箱で確かめました。総数だけでは、不良品を止められたかが分かりません。
- C 正解：実際の不良品をどれだけ止められたかという再現率
  解説：不良品を見つけたい対象とすると、再現率は実際の不良品のうち止められた割合です。この話ではAが0/1、Bが1/1でした。
- D 不正解：AIが良品と判定した箱の数だけ
  解説：良品判定が多くても、Aのように不良品が混じることがあります。人の検査結果と照合し、不良品の見逃しを確認する必要があります。

判断の決め手：何を避けたいかに合わせて数字を選ぶ。この話では実際の不良品を止めた割合。

### L004-Q03 / v1

Bは不良品を見逃さなかった一方、良品2箱も止めた。どんな影響に気を配る？

- A 正解：人の再確認が増え、出荷の手間や遅れにつながること
  解説：この工場では止まった良品2箱を人が再確認します。見逃しを減らす目的とともに、確認の手間や搬送の遅れにも気を配ります。
- B 不正解：Bは必ずどの工場でも優れていること
  解説：避けたい間違いや再確認の負担は現場で違います。今回の工場で候補にしたことと、常に優れていることは別です。
- C 不正解：今回の100箱だけで本番の安全が保証されたこと
  解説：試運転Bの結果はこの100箱での結果です。別の箱や条件でも同じ成績になるという保証ではありません。
- D 不正解：正解率が下がるので、Bは検討できないこと
  解説：Bの一致は98％でAより低い一方、不良品の見逃しは0箱でした。全体の割合と避けたい間違いの両方を見て検討します。

判断の決め手：Bを候補にしても、止まった良品の再確認とその負担は残る。
