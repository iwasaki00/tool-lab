## v0.1.3の漫画プロローグと再スタート

ホーム紹介：工場の出荷を手伝うことになったあなた。今日は、いつもと少し様子が違います。
L003-P00「今日は、いつもどおりのはずだった」は縦に並ぶ3コマ。いつもの出荷（集荷16:00）→午前の包装機停止→15時に復旧し箱が到着、の順に描く。あと1時間という説明は3コマ目で初めて出す。
「仕分け台へ行く」でAIの試行場面へ。過去の良品・不良の箱をモニターに表示し、「最初の箱を流す」で従来の誤判定へ進む。検査員の確認は合格、AIの判定は不良と別々に表示する。
全場面で検査員・箱・コンベアのSVGを共用。漫画の途中の読書位置とAI試行段階を保存し、旧版のprologueは漫画、sortingと未設定は従来の誤判定状態へ復帰する。既存の場面ID・添字は変更しない。
ホームの「最初から学ぶ」で今回の状態のみを初期化。回答履歴・過去の完了・復習候補・設定は保持する。

## 見本追加の体験（v0.1.1から継続）

場面タイトル：良品が、不良品レーンへ。
検査員：「あれ？ この箱、検査では合格だったのに」
主ボタン：検査済みの箱を見本に加える

対象箱Q=(60,60)。別の検査済みの良品W=(58,57)を見本へ追加する。初期6見本では不良のP4=(68,65)が最近傍（距離√89）。W追加後はWが最近傍（距離√13）になり、良品へ再判定される。対象Qそのものを正解つきで登録しない。判定の文字とレーンは既存のclassifyの計算値から描画する。

操作後にだけ、答え付きの見本から学ぶ教師あり学習の説明を出す。WとQを詳細分類シーンへ引き継ぐ。
同じローカルのインラインSVGで箱Qの位置、判定ラベル、見本Wの追加状態を切り替える。色に加えてレーン名・判定・検査結果・箱名でも状態を伝える。
知識マップからまとめへ直接進める。試験問題は任意で、まとめまたは演習メニューから取り組める。12問と48選択肢の解説・問題版はv0.1.0から変更していない。

## 概念

- supervised：教師あり学習 — 入力と正解の組から対応を学び、未知の入力の答えを予測する。
- unsupervised：教師なし学習 — 正解ラベルを与えず、データにある構造やまとまりを見つける。
- reinforcement：強化学習 — エージェントが環境で行動し、将来の累積報酬を高める方策を学ぶ。
- label：正解ラベル — 教師あり学習の見本につける目的変数。分類ではカテゴリ、回帰では数値。
- classification：分類 — 不良・良品など、離散的なカテゴリを予測する。
- regression：回帰 — 価格・温度など、連続的な数値を予測する。
- clustering：クラスタリング — 似た特徴を持つデータをグループにまとめる。
- kmeans：K-means — 近い中心へ割り当て、各グループの平均へ中心を更新する処理を繰り返す。
- agent：エージェント・行動 — 環境を観測して行動を選ぶ主体と、その選択。
- reward：報酬 — 行動や結果に対して環境が返す数値のフィードバック。
- generalization：汎化 — 学習時には見ていないデータでも適切に予測できる性質。学習データの正答率だけでは評価できない。

## 独自問題12問

各問題は版1。全選択肢の正誤・説明を以下に固定し、単体テストで4択すべての採点を確認する。意味の整合性は下記の原稿に基づきレビューする。

### L003-Q01 / v1

過去のメールに「迷惑／通常」の判定が付いている。新しいメールを判定するには？

- A 正解：教師あり学習
  解説：メールと正解判定の組から、新しいメールのカテゴリを予測できる。
- B 不正解：教師なし学習
  解説：構造の発見より、与えられた正解を予測する課題。
- C 不正解：強化学習
  解説：行動の試行錯誤や報酬が提示されていない。
- D 不正解：無作為に分類
  解説：利用できる正解の見本を活用していない。

判断の決め手：入力と正解の見本がそろっている。
関連知識：supervised, label
根拠範囲：SY-ML（機械学習の概要）

### L003-Q02 / v1

住宅の「価格」を数値で予測したい。「高価格／低価格」を予測する場合との違いは？

- A 不正解：両方とも分類
  解説：具体的な価格という連続値の予測は分類ではない。
- B 正解：価格は回帰、価格帯は分類
  解説：数値を予測する回帰と、カテゴリを予測する分類を区別している。
- C 不正解：価格は分類、価格帯は回帰
  解説：連続値とカテゴリの関係が逆。
- D 不正解：両方ともクラスタリング
  解説：正解価格を予測する課題であり、似たものをまとめる課題ではない。

判断の決め手：答えが連続値かカテゴリかを見る。
関連知識：regression, classification
根拠範囲：SY-ML（機械学習の概要）

### L003-Q06 / v1

## 内容レビュー

12問の正解は A・B・C・D・A・B・C・D・A・B・C・D。Q02は連続値とカテゴリ、Q03は誤ラベルの影響、Q05は群の解釈、Q08は報酬設計と目的のずれ、Q10は汎化をそれぞれ区別する。Q11は条件と目的の変化を明記し、単にデータ名だけで方式を断定しない。全48選択肢について、正解のみを支持し、それ以外には条件に合わない理由を記述した。

強化学習画面は方策を学習していないことを常時表示する。分類の予測は教材内の小規模データに対する計算であり、実務性能を保証しない。K-meansの群は正解ラベルではなく、初期値や特徴尺度の影響を受ける。
