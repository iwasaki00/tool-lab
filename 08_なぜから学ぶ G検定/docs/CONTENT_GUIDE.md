# 第0章の教材・出典

本文は依頼の4項目を基に構成した。AIの定義は「この教材では」と範囲を限定し、ルールベースも含む。機械学習の答え付き見本は一例とし、他の学び方への任意解説を追加した。

| 項目 | 説明・図 | 深掘り |
| --- | --- | --- |
| G検定 | 仕組みと活用、技術・歴史・評価・数理・法律倫理。実技と基礎知識の区別 | 出題範囲6分野と現在のアプリ対応範囲 |
| AI | 人が知能を使うような作業、ルールとデータ学習。包含図 | ルールが役立つ条件と、条件を書き切れなくなる例。史実のチェッカー研究 |
| 機械学習 | パターンをデータから見つける。見本と別の箱 | 答えなしの記録・行動結果の点数もある |
| ディープラーニング | 機械学習の一種、層を重ねて手がかりを学ぶ | 単純な手がかりから複雑な表現への理解用模式図。各層の役割は固定しない |

第0章は道案内。現在体験できるのはL003の3方式とL004のモデル評価。G検定全範囲への対応や合格保証は示さない。問題・試験日程・料金は追加していない。

## 根拠資料（2026-11-15確認）

- [JDLA「G検定とは・公式シラバス」](https://www.jdla.org/certificate/general/#general_No03)：G検定の目的、知識問題、技術分野・社会実装・数理統計・法律倫理の範囲を確認。
- [A. L. Samuel（1959）, Some Studies in Machine Learning Using the Game of Checkers](https://doi.org/10.1147/rd.33.0210)：チェッカーによる経験からの改善を紹介。DOI転送先は自動取得制限があったため、[Yale大学掲載の原論文](https://zoo.cs.yale.edu/classes/cs458/lectures/Samuels.pdf)の冒頭・導入を確認。「この研究だけが機械学習の起源」とはしていない。
- [LeCun, Bengio, Hinton（2015）, Deep learning](https://doi.org/10.1038/nature14539)：複数の処理層・抽象度の異なる表現について、Nature公式の検索結果に掲載された要旨を確認。公式本文の直接取得は認証リダイレクトにより不可。画像の層を固定的な役割として説明する根拠にはしていない。

工場と箱は学習用の架空例。サミュエルの研究場面と混同しないよう、本文にも区別を明記。長い原文引用は用いず、初学者向けに独自に要約した。実際の本文はsrc/components/BeginnerGuide.tsx、画像とプロンプトは[制作記録](ASSETS_v0.1.6.md)に収録。
