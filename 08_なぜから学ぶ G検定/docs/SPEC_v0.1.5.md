# v0.1.5 SECOND EPISODE 仕様

L003「機械学習の3つの方法」を維持し、L004「モデル評価／正解率99％なのに、不良品を見逃した」を第2話として追加する。初学者が、全体の正解率だけでは何を間違えたかは分からない、と図と操作で理解できることを目標とする。

## 通しの体験

1. 翌朝の試運転。同じ工場・検査員・箱・コンベアを使用。見本に使っていない100箱を流す。人が事前に検査した結果は学習用の見本へ加えず、試運転後の照合に使う。第1話を未読でも、導入でAIによる良品・不良の仕分けを説明する。
2. Aは100箱中99箱で一致。しかし人が不良と確認したBOX-100をAIが良品扱いで通す。まとまった100箱と、見逃した箱を同じSVGに描き、人の検査結果とAIの判定を別ラベルにする。
3. 同じ100箱で設定Bの結果を比較する。全体の一致・不良品の見逃し・良品の止めすぎを表と箱の図で並べる。A/Bの選択を問うクイズは置かない。
4. この工場では見逃しを減らしたいので、試運転Bを候補とする。止まった良品2箱は人が再確認する。Bが常に優れている、あるいは100箱だけで本番の安全が保証される、とは説明しない。
5. 結果後の「試験での呼び方」で正解率と再現率を説明する。混同行列は「詳しく見る」に配置。独自3問の演習と「ここで終える」は任意選択で、回答しなくても完了できる。

実時間の制限・100箱を1箱ずつ流す長い演出・冒頭のクイズ・AIの再学習は行わない。

## 教材の判定データと計算

人の検査結果は良品99箱・不良品1箱。A/Bは同じ箱IDと人の検査結果を持ち、AIの判定だけが異なる。件数・割合は100件の判定レコードから集計する。

| 項目 | A | B |
| --- | --- | --- |
| 良品を正しく通す | 99 | 97 |
| 不良品を見逃す | 1 | 0 |
| 良品を止めすぎる | 0 | 2 |
| 不良品を正しく止める | 0 | 1 |
| 判定一致 | 99/100＝99％ | 98/100＝98％ |
| 再現率 | 0/1＝0％ | 1/1＝100％ |

この話の再現率は、不良品を見つけたい対象とし、実際の不良品のうち不良として止められた割合。混同行列の行は人の検査結果、列はAIの判定とする。

箱は色に加え、ラベル・記号（○一致／!見逃し／Ⅱ止めすぎ）で区別する。

## 導線・保存

- コース一覧とL003の結末にL004への入口を置く。L003の「ここで終える」「試験問題で確認する」を残し、自動遷移はしない。
- L003のprogress・attemptsは従来のまま保つ。L004のevaluation・evaluationAttemptsを任意フィールドで独立保存。両方に「続きから学ぶ」「最初から学ぶ」を用意し、互いの状態や履歴を初期化しない。
- 完了記録はレッスンIDとセッションIDで保持する。両レッスンの再開始・再完了・統合で過去の記録を残す。
- JSON統合では両レッスンの更新日時を独立して比較する。古いバックアップにL004がなくても、現在のL004を消去しない。DB版・JSON形式版は1を維持。
- L004の段階はintro／discovery／comparison／ending／quiz。場面と閲覧の前提、問題番号、採点、日時、重複履歴を検証する。
- 挿絵はローカルのインラインSVGで表示し、本編・計算・問題を既存SWのキャッシュ資産へ含める。

## 演習

独自3問は「なぜ99％でも困るか」「見逃しを減らすなら何を見るか」「良品を止めすぎる影響」を扱う。全選択肢に物語と結び付く解説を付ける。L003の12問・解説・演習メニューと復習候補を維持する。
