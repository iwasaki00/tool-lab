# v0.1.3 STORY PROLOGUE 仕様

ホーム紹介は「工場の出荷を手伝うことになったあなた。今日は、いつもと少し様子が違います。」。期限や誤判定の結果を先に明かさない。

L003-P00「今日は、いつもどおりのはずだった」は、同じ画面に縦に並ぶ3コマで構成する。

1. いつもの出荷：検査員が学習者に「集荷 16:00」の札と通常の仕分けを説明する。
2. 午前、包装機が止まる：警告ランプと停止した空のベルト。箱が届かず仕分けを始められない。
3. 15時、箱が一気に届く：復旧したライン・箱の列・15時の時計・同じ集荷札。「あと1時間」はここで初めて提示する。

最後の主ボタンは「仕分け台へ行く」だけ。コマごとの次へ操作は設けない。スマートフォンでは自然な縦スクロールを利用する。

AI試行場面では、過去に検査した良品・不良の箱を小さなモニターに表示する。検査員の短い会話に続き「最初の箱を流す」で既存の誤判定へ進む。箱Qについて人の合格確認とAIの不良判定を別表示し、似た別の箱Wを見本に加える提案をする。

箱Q=(60,60)は見本に加えない。既存6見本の最近傍は不良のP4=(68,65)。別の検査済み良品W=(58,57)を追加するとWが最近傍となり、既存classifyの実計算で不良→良品になる。教師あり学習の説明は結果後に表示する。

保存形式はDB版1・JSON形式版1を維持。introStageへai-trialを追加する。新規・再開始はprologue→ai-trial→sorting。旧prologueは漫画へ、旧sortingまたは未設定は既存の操作状態へ復帰する。既存9場面の添字・IDを変更しない。漫画のスクロール位置を任意フィールドprologueScrollへ保存する。

「最初から学ぶ」は今回のL003の体験状態・読書位置だけを初期化する。回答・過去の完了・復習候補・設定・他の状態は保持する。12問と解説、任意演習、問題を解かない完了ルート、バックアップ、オフライン、教師なし学習・強化学習の本編を維持する。
