# WHY LEARN G / なぜから学ぶ G検定

v0.1.4 — FIRST EPISODE／工場の出荷を見届ける1話完結の教材。理由と操作から学ぶ、ブラウザ内完結の学習アプリです。L003「機械学習の3つの方法」だけを実装しています。公式教材・公式試験問題ではありません。

## 起動

Node.js 22.12以降（検証環境 Node.js 25.9.0）、npmを使用します。

```sh
npm ci
npm run dev
```

開発URLはターミナルに表示されます。PWAの確認には本番ビルドを使用してください。

```sh
npm run build
npm run preview -- --port 4173
```

ブラウザで http://127.0.0.1:4173/ を開きます。ビルド成果物は `dist/`。公開・デプロイは実施していません。

## 操作

ホーム「出荷ラインを見に行く」→3コマ漫画→「仕分け台へ行く」→「最初の箱を流す」→「検査済みの箱を見本に加える」→「搬送の様子を見る」→「似た搬送記録をまとめる」→「別の搬送経路を試す」→「2つの運び方を比べる」→必要なら「早く届ける／箱を丁寧に運ぶ」を切り替える→「出荷を見届ける」→3方式を振り返り「ここで終える」。試験問題・専門知識・詳細設定なしで完了できます。

- 主な目的は、検査を終えた箱を16時の集荷へ運ぶこと。実時間の制限はありません。
- 本編は、答え付きの別の見本追加（最近傍分類）→答えのない搬送記録の整理（K-means）→同じ2経路の報酬比較（概念デモ）の順です。変化を見てから名前を説明します。経路の比較は、方策を学習した結果ではありません。
- 各結果の「仕組みを詳しく見る」で、距離計算・散布図・クラスタ数・反復・行動ごとの点数を確認できます。出荷後は詳細教材・比較・知識マップも任意で開けます。「出荷の物語に戻る」で本編の保存状態へ戻れます。
- 最後の「試験問題で確認する」、またはメインの「演習」から既存12問と48選択肢の解説へ進めます。問題への回答は完了の条件ではありません。
- 「ここで終える」で完了を記録してホームへ戻ります。「最初から学ぶ」は今回のL003体験だけを初期化し、回答・過去の完了・復習候補・設定を保持します。
- 「続きから学ぶ」は漫画の読書位置、見本追加、グループ分け、条件切替、結末を復元します。旧版の進行は既存の場面から再開し、新しい物語へ強制移動しません。全編を体験する場合は「最初から学ぶ」を選べます。
- 「記録」で復習候補・履歴・JSON書出し／統合／置換を利用できます。既存の復習機能は変更していません。

IndexedDBの保存完了後に「端末に保存済み」と表示します。失敗時は再試行してください。保存失敗時も画面上の記録をJSONへ書き出せます。ブラウザのデータ消去・容量制限などによって記録が失われる場合があり、定期的なバックアップを推奨します。

初回オンライン時、本番ビルドのアプリ・教材資産をService Workerが取得します。「オフライン教材：準備済み」になってからオフライン利用してください。外部の公式参照リンクはオンライン接続が必要です。PWAはHTTPSまたはlocalhostで利用してください。iPhoneからPCのHTTP LANアドレスを開く場合、Service Workerが利用できないことがあります。

## 検証

```sh
npm test
npx playwright install chromium webkit
npm run test:e2e
```

E2Eは先に `npm run build` を実行し、ポート4173を空けてください。ChromiumとWebKitのiPhone SE相当設定を実行します。実機確認とは異なります。
