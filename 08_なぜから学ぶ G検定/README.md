# WHY LEARN G / なぜから学ぶ G検定

v0.1.1 — STORY FIRST。理由と操作から学ぶ、ブラウザ内完結の学習アプリです。L003「AIはどうやって学習するのか？」だけを実装しています。公式教材・公式試験問題ではありません。

## 起動

Node.js 22.12以降（検証環境 Node.js 25.9.0）、npmを使用します。

```sh
npm ci
npm run dev
```

開発URLはターミナルに表示されます。PWAの確認には本番ビルドを使用してください。

```sh
npm run build
npm run preview -- --port 4173
```

ブラウザで http://127.0.0.1:4173/ を開きます。ビルド成果物は `dist/`。公開・デプロイは実施していません。

## 操作

- 初回は「出荷ラインを見に行く」。挿絵の出来事を見て「検査済みの箱を見本に加える」を押すと、実計算で判定が変わります。回答や選択欄の操作は不要です。
- 中断済みなら「続きから学ぶ」を優先。「導入をもう一度見る」で体験をやり直せます。回答履歴は残ります。
- 導入では速度設定・用語説明を出さず、最初の操作後に説明と詳細分類への入口を表示します。
- 分類：見本のラベル・大きさ、未知の点の大きさ・重さを変更し、最近傍の予測を観察。
- K-means：Kとシードを選び、割当てと中心更新を1ステップずつ実行。連続再生・停止・速度変更が可能。
- 強化学習：固定された2つの行動例と報酬を比較する概念デモです。方策の学習はしません。
- 演習は任意：知識マップの後は「まとめへ」で進めます。「試験問題で確認する」かメインの「演習」から、従来の12問と全選択肢の解説を利用できます。解き直し履歴は消しません。
- 演習以外の8場面を見たら、まとめで学習した記録を付けられます。問題への回答は条件にしません。
- 記録：復習候補、履歴、JSONの書出し／統合／置換。置換は確認ダイアログ後に実行します。
- 途中終了はレッスン上部の「戻る・途中終了」。ホームの「続きから学ぶ」で保存位置から再開します。

IndexedDBの保存完了後に「端末に保存済み」と表示します。失敗時は再試行してください。保存失敗時も画面上の記録をJSONへ書き出せます。ブラウザのデータ消去・容量制限などによって記録が失われる場合があり、定期的なバックアップを推奨します。

初回オンライン時、本番ビルドのアプリ・教材資産をService Workerが取得します。「オフライン教材：準備済み」になってからオフライン利用してください。外部の公式参照リンクはオンライン接続が必要です。PWAはHTTPSまたはlocalhostで利用してください。iPhoneからPCのHTTP LANアドレスを開く場合、Service Workerが利用できないことがあります。

## 検証

```sh
npm test
npx playwright install chromium webkit
npm run test:e2e
```

E2Eは先に `npm run build` を実行し、ポート4173を空けてください。ChromiumとWebKitのiPhone SE相当設定を実行します。実機確認とは異なります。

## tool-labのメニューから利用する

```sh
npm run build:menu
```

`app/` にメニュー用の静的アプリを生成します。tool-labのメニューはこのディレクトリへリンクしています。ソース変更後は再実行してください。`app/` はGit管理対象、通常のビルドの `dist/` はGit対象外です。
