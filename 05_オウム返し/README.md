# オウム返し

iPhone SafariやPCブラウザで、話し終わった声を自動録音し、すぐにオウムのように再生するWebツールです。音声の検出・録音・加工・再生はすべて端末内で行い、音声データを外部へ送信しません。

## 起動方法

マイクは安全なコンテキストでのみ利用できるため、`index.html`を直接開くのではなく、HTTPSまたはlocalhostで実行します。PCでローカル確認する場合はリポジトリ直下で次を実行してください。

```powershell
py -3 -m http.server 8042 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8042/05_オウム返し/` を開きます。ChromeまたはEdgeの利用を推奨します。

## iPhoneでの使い方

1. HTTPSで公開されたページをSafariで開きます。
2. 「オウム返しを開始」をタップします。
3. マイクの使用を許可します。
4. 「聞いています」と表示されたら話しかけます。
5. 話し終えると、短い間のあとで自動的に声が再生されます。
6. 終了するときは「停止」をタップします。

初回起動時は、なるべく静かな場所で普段の声量で話してください。周囲音に応じて検出しきい値を自動補正し、詳細設定から手動調整もできます。

発話判定より前の音声は、既定で直近400msを「プリロール」として端末のメモリに保持します。発話を検出するとプリロールを録音の先頭へ加えるため、最初の音や子音が欠けにくくなります。保持時間は詳細設定から100〜1000msの範囲で変更できます。

## 声とエフェクト

Pitchは-12〜+12半音、Speedは0.5〜2.0倍で個別に設定できます。Pitch ShiftはGranular OLA方式で、再生時間を保ちながら声の高さを変更します。

普通、オウム、チビ、怪物、ロボット、宇宙人、洞窟、電話、スロー怪物、ハイパー、逆再生のプリセットを用意しています。ランダムは発話ごとにプリセットを選び、カオスは聞き取りやすい範囲で各パラメータを組み替えます。

「音声加工」ではPitch、Speed、Echo、Reverb、Robot、Tremolo、Low Pass、High Pass、Volume、Reverseを組み合わせたカスタム音声を作れます。感情、電子音リアクション、二回返し・音程変化・山びこ・左右パンなどのランダム行動も設定できます。設定はlocalStorageへ保存されます。

## 履歴・お気に入り

直近10件の録音をメモリ内に保持し、再生、現在の加工への変更、削除ができます。お気に入りへ登録した音声はBlobのままIndexedDBへ保存され、再生、名前変更、加工変更、削除ができます。localStorageには音声を保存しません。

録音中はリアルタイム波形、録音後は結果波形をCanvasへ表示します。

## GitHub Pages

このディレクトリはHTML/CSS/JavaScriptだけで構成されているため、そのままGitHub Pagesで公開できます。リポジトリの `Settings` → `Pages` で公開元を `main` ブランチの `/ (root)` に設定してください。公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/05_オウム返し/` になります。

## マイク権限とHTTPS

マイクを利用するには、GitHub PagesなどのHTTPS環境、またはlocalhostが必須です。ページを開いただけではマイクを開始せず、「オウム返しを開始」を押したときだけ許可を求めます。拒否した場合は、Safariのアドレスバーからページ設定を開き、マイクを「許可」に変更して再読み込みしてください。

## iOS Safariの注意事項

- iPhoneの音量が小さい場合は、消音設定とメディア音量を確認してください。
- Bluetoothイヤホン使用時は、録音・再生先の切り替えに時間がかかる場合があります。
- Safariをバックグラウンドへ移動したり画面をロックしたりすると、音声処理は継続できない場合があります。
- プリロール録音はAudioWorkletを優先し、録音結果を端末内でWAVに変換します。AudioWorkletが使えない環境では互換用の音声処理、それも使えない場合はMediaRecorderへ切り替えます。
- MediaRecorderへ切り替わった場合の対応形式はブラウザごとに異なります。本ツールは `audio/mp4`、`audio/webm;codecs=opus`、`audio/webm` の順に対応状況を調べます。
- スピーカー音の再録音は状態管理とエコーキャンセルで防ぎます。大音量や反響の強い場所では、再開待ち時間を長くすると安定します。

## デバッグ方法

画面下部の「デバッグ表示」を開くと、マイク権限、録音エンジン、音量、しきい値、録音時間、Pitch Shift方式、AudioBuffer情報、AudioNode概算、Effect Chain、IndexedDB、履歴件数、エラーとイベントログを確認できます。「クリア」でログだけを消去できます。PCの開発者ツールのConsoleにも詳細を出力します。

静的構成とエフェクト設定の回帰テストは次で実行できます。

```powershell
node 05_オウム返し/tests/run-tests.mjs
```
