# v1.2.0 — BEGINNER FRIENDLY UI 納品報告

## 1. Version

**v1.2.0 — BEGINNER FRIENDLY UI**。ローカル実装と関連テストを完了しました。GitHubへのpush・公開は行っていません。

## 2. 変更ファイル

- `index.html`：概要を初期表示とする4画面、上部メニュー、3ステップ案内、詳細設定への集約、共通の計算結果・復元表示。
- `script.js`：設定を保持する画面切り替え、おまかせ体験、結果の表示制御・フォーカス・スクロール、手動結果の購入方法表示。
- `style.css`：4メニュー、概要・使い方のレイアウト、コンパクトなカード、レスポンシブ表示、キーボード／タッチ操作への配慮。不要になった旧ツールメニュー専用CSSを整理。
- `verification/test-beginner-ui.cjs`：v1.2.0必須12項目とキーボード・タッチ・表示幅の関連テスト。
- `verification/test-samples.cjs`、`verification/test-experience.cjs`：新しい画面導線に合わせた既存テストの更新。旧エンジンとの照合を維持。
- `verification/v120-*.png`：PC・iPhone相当幅の4画面、サンプル結果、おまかせ体験の確認画像。
- `V1.2.0_REPORT.md`：本報告。

作業開始時、対象プロジェクトのGit差分はありませんでした。v1.1.0の実装を基準に変更しています。アプリは引き続き3ファイルで動作し、外部ライブラリ・ビルド環境・外部AI APIを追加していません。

## 3. 実装機能

- タイトル直下の4メニューを色・下線で識別。初回表示と再読み込み直後は概要です。
- 概要の「その定期券、本当に一番安い？」、短い説明・3つの主な機能、サンプル／手動計算へのボタン。
- 使い方を「金額→通う日→結果」の3ステップに整理。補足は必要なときに開けます。
- サンプル8カードを短い表示にし、「計算してみる」を明示。PCは4列または2列、幅740px以下は縦並びです。
- 自分で計算では、金額・期間・曜日を常時表示。券種の使用有無、祝日・週末除外、休暇、個別日変更は「詳細設定」へまとめました。
- 計算ボタンは「自分で計算」だけに表示し、画面下部への固定を解除しました。
- サンプル／手動で共通の結果表示を利用。手動計算にも最安購入方法を明記しました。
- サンプル名・変更済み表示・復元ボタンを結果の前にまとめ、サンプル実行後は復元ボタンと結果が分かる位置へ移動します。
- 「ツールメニューへ戻る」と旧ツール一覧の画面を削除しました。バージョン情報はフッターへ移動しました。

## 5. おまかせ体験の動作

サンプル05「月によって出勤日数が変動」を選びます。8・9・12・1月は週5日、10・11月は月曜のみという違いから、普通乗車券と定期券の組み合わせを体験できます。

ボタンを押すと、サンプル画面への切り替え、条件の設定、既存エンジンによる計算、使用サンプル名・今回の発見の表示まで自動実行します。結果は固定していません。

今回の実測（2027-08-01〜2028-01-31）では、**普通乗車券26日分＋1か月定期券3枚、101,856円**でした。普通乗車券のみ116,472円との差は14,616円です。将来は曜日配置により結果が変わり得ます。

最初のサンプル実行直前の設定を退避するv1.1.0の仕組みを利用します。切り替えや再読み込み後も復元でき、復元後は自分で計算の画面へ戻ります。

## 8. PC・iPhoneでの確認手順

1. PCのChromeまたはEdgeで `index.html` を開き、概要が最初に出ることを確認します。
2. 「まずはサンプルを試す」で8カードを確認し、任意のカードで自動計算・今回の発見を確認します。
3. 「元の設定に戻す」で自分で計算へ戻り、金額・期間・曜日を設定します。必要なら詳細設定を開きます。
4. 概要・使い方・サンプルへ切り替えてから自分で計算に戻り、入力が保持されることを確認します。
5. 概要の「おまかせ体験」を押し、サンプル05の名前、購入方法、復元ボタンを確認します。
6. 手動でも計算し、カレンダー／線表、CSVダウンロード、PDFボタンからの印刷画面を確認します。
7. PCの開発者ツールで幅375／390pxの端末表示に切り替え、4メニュー・カード・入力・詳細設定を操作します。幅320pxも確認できます。
8. iPhone実機を確認する場合は、同じWi-Fi内のローカルHTTP配信でこのフォルダーへアクセスし、Safariで同じ操作を試してください。今回、LAN配信や公開サーバーへの配置は行っていません。

確認画像の例：`verification/v120-390-overview.png`、`verification/v120-1280-guide.png`、`verification/v120-390-calculate.png`、`verification/v120-iphone-guided.png`。

## 9. 既知の制限

- iPhone実機・Safariは未確認です。確認済みなのはChromeでの画面幅・タッチ操作の再現です。
- PDFは印刷画面用HTML生成まで検証しました。OSの印刷ダイアログ操作と実ファイル保存は未実施です。
- メニュー切り替え時は選択先の先頭を表示します。画面ごとのスクロール位置や選択中メニューは保存せず、再読み込み時は概要に戻ります。入力内容とサンプルの復元元は保存されます。
- 復元は同じブラウザー・同じオリジンのlocalStorageを使います。ブラウザーデータ削除後や別端末への引き継ぎは対象外です。
- 2028年以降の祝日推定、同額最安ルートの1案表示など、v1.1.0の既存制限を引き継いでいます。
