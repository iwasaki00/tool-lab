# Tilt 3D Lab / 傾き3D実験室

スマートフォンの姿勢センサー、またはPCのマウス位置に応じて、画面内のカードを立体的に覗き込むような視差を作る実験用Webアプリです。

## Version

**0.1.1 — Phase 1**

### Version 0.1.1の変更点

- 端末の物理的な傾き `tiltX` / `tiltY` と、描画方向 `viewX` / `viewY` を分離
- 左右反転（`invertX`）と上下反転（`invertY`）を独立して切り替え可能に変更
- 実機調整用にDEVICE／VIEWの方向マップと両方の数値をDEBUG表示へ追加
- 初期値は実機確認結果を踏まえて左右・上下とも反転ON

端末やブラウザによってセンサー軸の体感が異なる場合があります。DEBUGをONにし、「左右反転」「上下反転」を個別に切り替えて、自然に覗き込める組み合わせへ調整できます。反転は画面方向補正とニュートラル差分の計算後に適用されるため、基準姿勢には影響しません。

## 今回実装した範囲

- `DeviceOrientationEvent` から alpha / beta / gamma を取得
- 物理傾きと描画視点を分離し、左右・上下を独立して反転
- 画面方向を考慮した `tiltX` / `tiltY`（-1〜+1）への正規化とクランプ
- 現在姿勢を基準にできるニュートラルリセット
- `requestAnimationFrame` とLERPによるスムージング
- CSS perspective、カード回転・移動、3層パララックス、動的な光沢
- 感度および3段階のスムージング設定
- センサー状態・姿勢値・FPSのDEBUG表示
- センサー利用不可時のPCマウスエミュレーション
- `prefers-reduced-motion` とiPhoneのSafe Areaへの配慮

## ローカル確認方法

ES Modulesを使用するため、ファイルを直接開かずローカルHTTPサーバーから表示します。

```powershell
cd 07_スマホ傾き疑似3Dツール
py -3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。PCではカード付近でマウスを動かすと傾きを疑似操作できます。

## iPhoneでの確認方法

1. HTTPSでアクセスできる場所へファイルを配置し、iPhone Safariで開きます。
2. 「モーション開始」をタップします。
3. 表示された許可ダイアログで許可します。
4. 端末を自然に持ち、「現在位置を中央にする」をタップしてから傾けます。

iOSではモーション許可APIをボタン操作の中から呼び出しています。拒否した場合はSafariまたはiOSの設定でサイトのモーションアクセスを見直してください。

## HTTPS / Secure Context

端末の姿勢センサーは原則としてHTTPSのSecure Contextでのみ利用できます。`localhost` は開発用途の安全なオリジンとして扱われますが、同一LAN内のPCへIPアドレスでアクセスする方法はHTTPのため、iPhoneではセンサーが使えないことがあります。実機確認にはHTTPS対応のホスティングまたはHTTPS開発環境を使用してください。

## Androidでの確認方法

HTTPSで配置したページをAndroid Chromeで開き、「モーション開始」をタップします。機種やOS設定によってはセンサー利用を制限している場合があります。状態表示とDEBUG値で受信状況を確認できます。

## PCのマウス疑似操作

カード領域の中央が `tiltX = 0`, `tiltY = 0`、左右端・上下端がそれぞれ約 `-1` / `+1` です。領域からマウスを外すと中央へ滑らかに戻ります。実センサー値を受信した後はセンサー入力を優先します。

## 既知の制限

- ブラウザや端末ごとに姿勢センサーの軸・感度・取得頻度には差があります。
- 画面回転時は新しい向きで自動的にニュートラル位置を取り直します。
- Phase 1はCSSによる疑似3Dであり、実際の3D空間やオクルージョンは扱いません。
- iOSシミュレーターや多くのデスクトップ環境では実センサーを確認できません。
