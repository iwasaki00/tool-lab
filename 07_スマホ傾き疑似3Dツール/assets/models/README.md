# Bundled sample model

`sample-viewer.glb` is a tiny, uncompressed glTF 2.0 binary created specifically for Tilt 3D Lab browser testing.

- Generator: Tilt 3D Lab QA generator
- Geometry: asymmetric box, 12 triangles
- Animation: one rotation clip (`Turntable QA`)
- External textures or binary references: none
